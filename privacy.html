Datenschutzerklärung

Stand: 4. November 2026

1. Zweck der Anwendung

Diese Anwendung wird ausschließlich für die private Sicherung eines eigenen Google-Drive-Kontos verwendet. Sie basiert auf der Open-Source-Software rclone. Es handelt sich nicht um einen öffentlich angebotenen Dienst.

2. Zugriff auf Google-Daten

Die Anwendung verwendet die Google Drive API mit ausschließlichem Lesezugriff. Sie kann Dateien und Ordner abrufen sowie Google-Dokumente in lokale Office-Dateiformate exportieren. Dateien im Google Drive werden nicht verändert oder gelöscht.

3. Speicherung und Verwendung

Abgerufene Dateien werden ausschließlich auf einem privaten lokalen Windows-Computer gespeichert. Das Backup umfasst aktuelle Dateien sowie ältere und gelöschte Dateiversionen. Diese bleiben bis zur manuellen Löschung erhalten.

OAuth-Zugangsdaten werden lokal in der rclone-Konfiguration gespeichert. Sie werden nicht auf dieser Website veröffentlicht.

4. Weitergabe von Daten

Es erfolgt keine Weitergabe der abgerufenen Google-Drive-Inhalte an Dritte. Insbesondere werden keine gesicherten Dateien an GitHub oder andere Cloud-Speicherdienste übertragen.

5. Widerruf und Löschung

Der Zugriff kann jederzeit in den Sicherheitseinstellungen des Google-Kontos widerrufen werden. Lokal gespeicherte Daten und Zugangstoken können jederzeit gelöscht werden.

6. Website

Diese Informationswebsite wird über GitHub Pages bereitgestellt. Die Website selbst verwendet keine Analysewerkzeuge und setzt keine eigenen Cookies. GitHub kann beim Betrieb des Hostings technische Zugriffsdaten verarbeiten.

7. Kontakt

Kontakt für Datenschutzfragen: datenschutz@nanomondo.de
